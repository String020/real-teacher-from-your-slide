# Exam Compression Mode

Use this mode for final review, last-minute synthesis, quick-reference sheets, and compressed exam checklists.

## Default output: Exam Compression Pack

Include:

1. Problem-type entry table.
2. Formula usage conditions.
3. Standard solution steps.
4. Common mistakes.
5. Final review checklist.

Use "if you see -> use -> write -> check" formatting when helpful.

## Frequency and priority claims

Only include high-frequency or priority claims when supported by uploaded resources such as sample exams, past exams, problem sheets, revision scopes, marking guides, or instructor guidance.

If evidence is insufficient, write conservative language such as:

"The uploaded resources support practising this topic, but they do not provide enough evidence to rank it as high-frequency."
