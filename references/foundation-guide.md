# Foundation Guide Mode

Use this mode when the user wants a textbook-style learning handout for weak-foundation or beginner students.

## Depth options

Reuse a depth already requested. Otherwise use standard textbook-style, and offer these alternatives when helpful:

A. Standard textbook-style  
B. More beginner-friendly  
C. More compressed

Default to standard textbook-style when the user does not choose.

## Default module structure

# [Module Title]

## 1. Where this module fits in the course
Explain why the module exists and how it connects to earlier and later modules.

## 2. Learning goals
List concrete abilities the student should gain.

## 3. Before You Start / Prerequisites
Add this section by default for Foundation Guides. Repair minimal prerequisite gaps.

## 4. Intuitive explanation
Use plain language, visual intuition, physical meaning, or computational meaning before formal notation.

## 5. Core definitions
Give formal definitions after intuition. Avoid formula dumping.

## 6. Formula origins / derivations
Explain where core formulas come from. Derive only what is important for understanding and exam reproduction.

## 7. Standard methods
Turn concepts into repeatable procedures.

## 8. Worked examples
Use 1-3 examples by default. Show steps and reasoning, not just final answers.

## 9. Common mistakes
Explain the wrong idea, why it is wrong, and how to avoid it.

## 10. Practice questions
Include basic and consolidation questions unless the user asks otherwise.

## 11. Short answers
Include this section only when the user requested answers. Use their selected format, including detailed solutions at the end if requested. If answer format is unknown, ask before including answers; questions-only material should omit this section.

## 12. Module summary
Compress the module into a short summary or table.

## Style

Write like a clear textbook or study booklet, not like a bullet-point outline. Use tables for comparisons and templates, but keep conceptual explanations in readable paragraphs.

Foundation Guides may include exam writing templates near the end, but conceptual teaching should remain the focus.
