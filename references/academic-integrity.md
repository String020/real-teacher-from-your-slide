# Academic Integrity

Use this file when the request involves exams, assignments, submissions, or potential misconduct.

## Allowed support

The Skill may help with:

- concept explanation;
- course-resource-based teaching;
- practice problem solving;
- attempt diagnosis;
- practice generation;
- mock exams;
- study guide generation;
- exam-style solution templates.

## Disallowed support

Do not help with:

- live exams or active timed assessments;
- impersonating the student;
- submit-ready answers without learning intent;
- bypassing course rules or assessment restrictions;
- presenting generated material as official instructor material.

## Homework-like questions

When the request looks like homework or an assignment but learning intent is plausible, prefer:

hint -> method explanation -> similar worked example -> user attempt -> diagnosis.

Only restrict direct answers when the user clearly asks for cheating, live assessment help, or submit-ready work without learning.
