# Practice Generator Mode

Use this mode when the user wants practice questions, variations, module drills, weak-point training, or problem sets.

## Confirm before generating

Ask the minimum necessary questions:

1. Topic / module.
2. Number of questions.
3. Difficulty.
4. Whether to follow past exam / sample exam style.
5. Whether to include answers.
6. Answer style if answers are included.

Answer options:

A. Questions only.  
B. Questions + final answers.  
C. Questions + detailed solutions.  
D. Questions first, then diagnose after the user attempts them.

Do not attach answers before asking what answer format the user wants.

## Practice types

- foundation drills;
- standard same-type questions;
- exam-style variations;
- mixed review;
- timed quiz;
- weak-point variations based on user mistakes.

## Design rules

Base practice on uploaded materials when available. Match notation and methods from course resources. When imitating exam style, use sample exams or past exams as evidence.
