# Source Grounding and Resource Conflicts

Use this file when generating formal artifacts or when uploaded resources disagree.

## Evidence record

For multi-source work and formal artifacts, keep a compact working record for important scope, method, formula, and exam-priority claims:

| Claim | Source | Locator | Evidence kind | Limitation or conflict |
|---|---|---|---|---|
| Example: Topic A is included | Current scope document | Section 2 | Explicit statement | No weighting supplied |

Use actual filenames and page, slide, question, or section labels. If printed page numbers differ from PDF positions, distinguish them. For unpaginated text, use a heading. If no reliable locator is available, say so rather than inventing one. Do not reproduce this table in every short explanation.

Separate explicit instructor statements from patterns observed in supplied questions and from supplementary teaching examples. A topic appearing in one sample question supports practising it; it does not establish its frequency or future weighting.

For incomplete scans or unavailable files, record what was actually readable and avoid claims about the unreviewed portion. Build the final source section from this record, with enough detail for a student to find the supporting passage.

## Formal artifact grounding

For formal artifacts, include source grounding separately from the main teaching content.

Formal artifacts include:

- PDF study guides;
- slide decks;
- long Markdown notes;
- knowledge outlines;
- exam outlines;
- foundation guides;
- exam strategy packs;
- mock exams;
- practice packs.

Preferred section titles:

- Source Basis;
- Resources Used;
- Evidence Notes;
- Material Coverage.

For PDFs, use a separate source page near the end or beginning. For slides, use a final or appendix slide. For Markdown, use a final source section.

Do not clutter the main content with source labels unless strict grounding is required.

## Resource conflict priority

Resolve conflicts according to the kind of claim. A document's authority on exam scope does not automatically make it authoritative on formula correctness or permitted resources.

For exam coverage and preparation, use this starting order where sources address the same issue:

1. current instructor-provided exam scope / revision list;
2. current sample exam / mock exam / marking guide;
3. current semester lecture slides and lecture notes;
4. current problem sheets / tutorials / applied class materials;
5. older past exams;
6. general notes or external explanations.

For permitted formulas, tools, or methods, use the current instructor's assessment rules and allowed-resource sheet. For mathematical claims, check definitions, assumptions, notation, and the calculation itself; do not silently teach an apparent typo as correct because it appears in a high-ranked source.

If conflict is minor, explain the difference and use the more exam-relevant source.

If a conflict affects exam scope, allowed methods, formula usage, or marking style and the current authoritative instruction does not resolve it, cite both passages and ask which source governs the assessment. Continue independent, unaffected topics while that question is unresolved. Explain a demonstrable calculation error directly and distinguish it from uncertainty about course policy.

## Insufficient evidence

If evidence is insufficient, say so. Do not infer exam priority from slides alone unless the user asks for a speculative study plan and the uncertainty is clearly labelled.
