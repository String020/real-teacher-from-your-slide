# Source Grounding and Resource Conflicts

Use this file when generating formal artifacts or when uploaded resources disagree.

## Formal artifact grounding

For formal artifacts, include source grounding separately from the main teaching content.

Formal artifacts include:

- PDF study guides;
- slide decks;
- long Markdown notes;
- knowledge outlines;
- exam outlines;
- foundation guides;
- exam strategy packs;
- mock exams;
- practice packs.

Preferred section titles:

- Source Basis;
- Resources Used;
- Evidence Notes;
- Material Coverage.

For PDFs, use a separate source page near the end or beginning. For slides, use a final or appendix slide. For Markdown, use a final source section.

Do not clutter the main content with source labels unless strict grounding is required.

## Resource conflict priority

When uploaded resources conflict, prioritize by exam relevance:

1. current instructor-provided exam scope / revision list;
2. current sample exam / mock exam / marking guide;
3. current semester lecture slides and lecture notes;
4. current problem sheets / tutorials / applied class materials;
5. formula sheet / allowed exam resources;
6. older past exams;
7. general notes or external explanations.

If conflict is minor, explain the difference and use the more exam-relevant source.

If conflict affects exam scope, included/excluded topics, allowed methods, formula usage, or marking style, point out the conflict and ask the user which source should be authoritative.

## Insufficient evidence

If evidence is insufficient, say so. Do not infer exam priority from slides alone unless the user asks for a speculative study plan and the uncertainty is clearly labelled.
