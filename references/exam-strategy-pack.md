# Exam Strategy Pack Mode

Use this mode when the user wants exam-ready methods, templates, and practice.

## Purpose

Convert uploaded resources into problem-type recognition, formula usage conditions, standard solution workflows, common mistakes, worked examples, and quick-reference tables.

## Default structure

# Exam Strategy Pack

## 1. Exam Scope Positioning
State what the uploaded resources support. Avoid unsupported priority ranking.

## 2. Problem-Type Entry Table
| If you see | Use | Why | Standard steps | Watch out |
|---|---|---|---|---|

## 3. Formula + Usage Conditions
For each formula or method, explain when it applies, what must be checked first, and common misuse.

## 4. Standard Solution Workflows
Write procedures students can reproduce in an exam.

## 5. Exam Writing Templates
Show concise answer structures that fit exam scripts.

## 6. Common Mistakes
Include both conceptual and mechanical errors.

## 7. Worked Examples
Use examples that demonstrate exam writing and method selection.

## 8. Similar Practice Questions
Reuse an answer format already requested. Ask only if it is unknown before attaching answers to generated practice.

## 9. Final Quick-Reference Table
Use "if you see -> use -> write -> check" style.

## Priority rule

Do not include high / medium / low exam priority by default. Add it only when uploaded exam-like materials support it. A requested speculative study plan must be labelled as a recommendation with an explicit basis, not as measured exam frequency.
