# Exam Outline Mode

Use this mode to convert course resources into an exam-facing map.

## Purpose

An Exam Outline focuses on exam scope, problem types, formula conditions, standard solution workflows, common loss points, and training direction.

It is separate from Knowledge Outline by default.

## Default structure

# Exam Outline

## 1. Exam Scope Judgment
State what topics are supported by the uploaded resources. Distinguish known scope from uncertain scope.

## 2. Problem-Type Entry Table
Use a table:

| If you see | It usually means | Method | Standard steps | Common mistakes |
|---|---|---|---|---|

## 3. Formula Usage Conditions
Use a table:

| Formula / method | Use when | Do not use when | Check before using |
|---|---|---|---|

## 4. Standard Solution Workflows
For each topic, list an exam-reproducible sequence of steps.

## 5. Common Loss Points
List recurring exam mistakes such as missing conditions, sign errors, special cases, answer format, or method selection errors.

## 6. Training Direction
Recommend practice types. Include exam-priority ranking only if supported by uploaded exam-like resources. If the user asks for a speculative study plan without such evidence, label it as a study recommendation and explain its basis; do not present it as observed exam frequency.

## 7. Next Steps
Suggest Exam Strategy Pack, Practice Generator, Mock Exam, Problem Tutor, or Exam Compression.

## Evidence rule

Do not claim high-frequency or exam-priority status without evidence from sample exams, past exams, problem sheets, revision scopes, or instructor-provided materials.
