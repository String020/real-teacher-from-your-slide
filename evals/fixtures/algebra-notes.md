# Algebra notes

## Section 1: Linear equations

A linear equation can be solved by applying the same reversible operation to both sides. Example: 3x+6=12 implies x=2.

## Section 2: Checking an answer

Substitute a proposed value into the original equation and check that both sides are equal.
